# Project Overview
Use multi-stage builds to produce a small, production-ready container for a React application. Compare it with a single-stage baseline and explain the improvements in size, security, and deploy speed.

# Objective

Create both a single-stage Docker image and an optimized multi-stage Docker image for a React application. Compare the image sizes, analyze the optimization benefits, and deploy the application using a production-ready Nginx runtime container.

Complete this assignment locally on your own computer where Docker is installed and running. A cloud VM is not required.

# Perequisite

- Docker installed and running on your local computer
- Git installed
- Basic Linux command knowledge
- Basic React knowledge
- Internet connectivity
